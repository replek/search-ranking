# Ранжирование поисковых результатов
## Решение

1. **Препроцессинг.** Исправлены ошибки (UTF-8, прочитанный как cp1251), удалены знаки ударения, HTML-теги и сущности, вики-разметка,
   невидимые символы; из заголовков убраны заглушки и суффикс « — Википедия», пустые заголовки восстановлены по `article_id`.
   Вход моделей: «запрос» и «заголовок. фрагмент».
2. **Валидация.** 5 фолдов GroupKFold по запросам. LLM-модели обучены на фолдах 1–4, фолд 0 — проверка смеси.
3. **Модели**

   | Модель | Дообучение | Вход | NDCG@10, фолд 0 |
   |---|---|---|---|
   | `BAAI/bge-reranker-v2-m3` | полное, 5 фолдов, 1 эпоха, lr 1e-5 | 384 | 0.9342 |
   | `Qwen/Qwen3-Reranker-4B` | LoRA r16, 1 эпоха, lr 1e-4 | обучение 448, предсказание 1024 | 0.9542 |
   | `Qwen/Qwen3-Reranker-8B` | LoRA r16, половина эпохи, lr 1e-4 | 1024 | 0.9581 |

   Лосс у всех моделей — softmax по кандидатам запроса. Скор Qwen — логит «yes» минус логит «no».
4. **Смесь.** Скоры нормируются внутри запроса (z-оценки): `qwen8 + qwen4 + 0.5 · ce`.

## Запуск

```
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute solution.ipynb   # результат: outputs/submission.csv
```

`train.csv`, `test.csv`, `sample_submission.csv` кладутся рядом с ноутбуком. Ноутбук обучает все модели с нуля.

Система: Linux, обучение и инференс на NVIDIA Tesla T4 16 ГБ (Kaggle). CE и Qwen 4B — одна GPU 16 ГБ, Qwen 8B — 2×16 ГБ или одна GPU от 32 ГБ.
Время на T4: CE ~4 ч, Qwen 4B ~8 ч, Qwen 8B ~7.5 ч.
